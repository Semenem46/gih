# 🤖 Бот-воронка под лид-магнит

Готовый Telegram-бот, который:
1. Раздаёт твой лид-магнит (`База_TG-чатов_для_лидгена_2026.xlsx` — 88 целевых чатов).
2. Собирает контакт лида (имя + опционально телефон).
3. Прогревает автоматическими follow-up сообщениями: **30 мин → 1 день → 3 дня → 7 дней**.
4. Считает конверсии по источникам трафика (Reels, TikTok, канал — каждый со своей UTM-меткой).
5. Уведомляет тебя в личку о каждом новом лиде.

---

## 🟢 Запуск за 5 минут (для не-программиста)

> Нужен **компьютер с интернетом** (Mac/Windows/Linux) или **VPS** (если хочешь, чтобы бот работал 24/7 без твоего компа).

### Шаг 1 — Создай бота в Telegram

1. Открой в Telegram бот **[@BotFather](https://t.me/BotFather)** и нажми Start.
2. Отправь команду **`/newbot`**.
3. Введи имя бота (любое, например: `Никитосик · База чатов`).
4. Введи логин бота — должен заканчиваться на `bot` (например: `nikitosik_chats_bot`).
5. BotFather пришлёт сообщение с **токеном** — длинная строка вида `1234567890:AAH...XYZ`. **Скопируй её.**

### Шаг 2 — Узнай свой Telegram-ID

1. Открой бот **[@userinfobot](https://t.me/userinfobot)** → нажми Start.
2. Он пришлёт твой ID — число, например `123456789`. **Скопируй.**

### Шаг 3 — Поставь Python (если ещё нет)

- **Mac**: открой Terminal, выполни `brew install python@3.11` (если нет brew — поставь с https://brew.sh).
- **Windows**: скачай Python 3.11 с https://www.python.org/downloads/windows/ (при установке поставь галочку **Add Python to PATH**).
- **Linux/Ubuntu**: `sudo apt install python3.11 python3.11-venv` — обычно уже есть.

Проверь: `python3 --version` → должно быть `Python 3.11.x` или новее.

### Шаг 4 — Скачай бота и настрой

1. Распакуй архив с ботом в любую папку, например `~/leadbot`.
2. Открой Terminal (Mac/Linux) или PowerShell (Windows), перейди в папку:
   ```bash
   cd ~/leadbot
   ```
3. Скопируй файл-шаблон конфига:
   ```bash
   cp .env.example .env
   ```
4. Открой `.env` любым текстовым редактором (TextEdit / Блокнот / VSCode) и заполни **минимум 2 строки**:
   ```ini
   BOT_TOKEN=сюда_токен_от_BotFather
   ADMIN_IDS=твой_id_от_userinfobot
   ```
   Остальное можно не трогать. Если хочешь — впиши:
   ```ini
   AUTHOR_NAME=Никита
   AUTHOR_USERNAME=твой_telegram_логин_без_собачки
   SUPPORT_USERNAME=твой_telegram_логин_без_собачки
   LINK_BOOK_CALL=https://ссылка_на_твой_calendly_или_форму
   ```
   Если у тебя пока **нет кейсов** — оставь `LINK_CASES=` пустым. Кнопка «Кейсы» просто не появится в боте. Когда появятся — впишешь и перезапустишь бот.

   Если **нет ссылки на запись на разбор** (Calendly/форма) — оставь `LINK_BOOK_CALL=` пустым тоже. Тогда люди будут писать тебе через кнопку «Написать лично» (если задан `SUPPORT_USERNAME`).

### Шаг 5 — Установи зависимости и запусти

```bash
python3 -m venv .venv
source .venv/bin/activate          # на Windows: .venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

В Terminal должно появиться:
```
INFO:__main__:Bot started polling
```

**Готово.** Открой своего бота в Telegram (по ссылке от BotFather) → нажми **Start** → проверь, что приходит приветствие, файл и follow-up через 30 минут.

> Чтобы остановить бота — `Ctrl+C` в Terminal.

## 🚀 Чтобы бот работал 24/7 (когда ты выключил комп)

Купи самый дешёвый VPS (Timeweb / Beget / Reg.ru за 200 ₽/мес), залей туда папку с ботом и запусти как systemd-сервис:

`/etc/systemd/system/leadbot.service`:
```ini
[Unit]
Description=Telegram lead-magnet bot
After=network.target

[Service]
WorkingDirectory=/home/ubuntu/leadbot
ExecStart=/home/ubuntu/leadbot/.venv/bin/python bot.py
Restart=always
RestartSec=5
User=ubuntu

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now leadbot
sudo journalctl -u leadbot -f      # смотреть логи
```

Альтернатива — Docker:
```bash
docker build -t leadbot .
docker run -d --name leadbot --env-file .env -v $(pwd)/leads.db:/app/leads.db leadbot
```

## 🎛 Команды бота (для тебя как админа)

Ты узнаешься по `ADMIN_IDS` из `.env`. В личке с ботом:

| Команда | Что делает |
|---------|-----------|
| `/stats` | Сколько лидов всего, за день/неделю, конверсия в файл, источники UTM |
| `/export` | Присылает CSV со всеми лидами (имя, username, телефон, источник, дата) |
| `/broadcast <текст>` | Рассылает всем подписчикам. Можно reply-ом на сообщение с фото/файлом — пересылается as-is |

## 🔗 Ссылки под разные источники трафика (UTM)

Один бот — много deep-link-ов. Под каждую соцсеть/ролик своя ссылка:

- Из Reels: `https://t.me/твой_бот?start=reels`
- Из TikTok: `https://t.me/твой_бот?start=tiktok`
- Из Shorts: `https://t.me/твой_бот?start=shorts`
- Из канала: `https://t.me/твой_бот?start=channel_pin`

Потом `/stats` покажет, какой канал даёт больше всего лидов.

## ✏️ Что точно стоит поменять под себя

| Что | Где |
|-----|-----|
| Приветствие, follow-up сообщения | `texts.py` (4 шага drip-цепочки внизу файла) |
| Тайминги drip-цепочки (по умолчанию 30/1440/4320/10080 мин) | `.env` → `DRIP_SCHEDULE_MINUTES` |
| Ссылки в кнопках («Записаться», «Кейсы») | `.env` → `LINK_CASES`, `LINK_BOOK_CALL` |
| Имя/юзернейм автора | `.env` → `AUTHOR_NAME`, `AUTHOR_USERNAME` |
| Сам файл лид-магнита | заменить файл в `assets/` + поправить `LEAD_MAGNET_FILE` в `.env`, если переименовал |

> **Сильнее всего тексты в `texts.py`** — там болванка drip-цепочки. Тексты написаны под человека **БЕЗ готовых кейсов** — упор сделан на наблюдения, экспертизу и бесплатный разбор. Когда у тебя появятся реальные кейсы (47 заявок за месяц, такая-то компания платит X, и т.п.) — замени Drip #1 (`👀 3 ошибки…`) на «Кейс: …». В файле есть пометка `case_placeholder` — найди и перепиши.
>
> **Бот сам по себе не продаёт — продают тексты.**

## 📊 Воронка: как всё связано

```
Трафик из Reels/TikTok/канала
          │
          ▼
   t.me/твой_бот?start=reels
          │
          ▼
   /start  →  WELCOME   →  [Забрать базу 📊]
                              │
                              ▼
                       ASK_PHONE  ──►  пропустил / поделился контактом
                              │                              │
                              └──────────┬───────────────────┘
                                         ▼
                       📎 FILE + AFTER_FILE  ──►  кнопки [Записаться · Кейсы · Контакт]
                                         │
                                         ▼
                             Drip #0 (через 30 мин)  — польза + soft-CTA
                             Drip #1 (через 1 день)  — кейс
                             Drip #2 (через 3 дня)   — типичная ошибка
                             Drip #3 (через 7 дней)  — последний оффер на разбор
                                         │
                                         ▼
                                 Тишина / личное общение
```

Каждый шаг попадает в `events` в SQLite — `/stats` показывает, до какого шага доходят люди.

## 🆘 Что-то сломалось?

| Симптом | Что проверить |
|---------|---------------|
| `Не задана переменная окружения BOT_TOKEN` | Нет файла `.env` рядом с `bot.py` или в нём пустой `BOT_TOKEN`. |
| Бот не отвечает на `/start` | Проверь, что в Terminal виден `Bot started polling`. Если нет — поправь токен. |
| Не приходит файл | В папке `assets/` должен лежать `База_TG-чатов_для_лидгена_2026.xlsx`. Если переименовал — поправь `LEAD_MAGNET_FILE` в `.env`. |
| Тебе не приходят уведомления о новых лидах | Проверь `ADMIN_IDS` в `.env`. И **напиши боту от своего аккаунта хотя бы раз** — иначе Telegram не даст ему писать тебе. |
| Drip не отправляется | Шедулер запускается раз в минуту — посмотри логи. Если `leads.db` повреждён, удали — пересоздастся. |
