# 🚀 Быстрый старт через Termius (5 команд)

Это гайд для тех, кто SSH-ит на сервер из Termius. Просто копируй и вставляй блоки команд по очереди.

---

## Шаг 0. Что у тебя должно быть

✅ Сервер на Ubuntu (купи на timeweb / aeza / ihor — 200–500₽/мес)
✅ Доступ по SSH через Termius
✅ TG-бот (создай у `@BotFather` → `/newbot` → получи токен)
✅ Виртуальный TG-номер для парсера (sms-activate.org, ~50₽)

---

## Шаг 1. Подключись к серверу через Termius

Open Termius → New Host → IP / login / password от хостера → подключись.

Дальше всё в SSH-сессии.

---

## Шаг 2. Закинь файлы на сервер

Можно по-разному — выбери удобное:

**Вариант А (через Termius SFTP).** В Termius есть кнопка SFTP → перетащи папку с файлами в `/home/ubuntu/leadbot` (или куда захочешь).

**Вариант Б (через wget/архив).** Если тебе пришлю zip-файл, на сервере:
```bash
cd ~
wget <url-к-zip>
unzip leadbot.zip
mv leadbot-* leadbot
cd leadbot
```

После этого ты должен оказаться в `~/leadbot` и видеть:
```bash
ls
# parser_apex_ai.py  query_engine.py  chat_discoverer_apex.py  setup.sh  start.sh  bot/  ...
```

---

## Шаг 3. Установка одной командой

```bash
cd ~/leadbot
chmod +x setup.sh start.sh
./setup.sh
```

Скрипт сам поставит Python, tmux, venv и все зависимости. Займёт 2–3 минуты.

В конце он создаст файл `bot/.env` и попросит туда вписать токены.

---

## Шаг 4. Заполни `.env`

```bash
nano bot/.env
```

Откроется простой редактор. Замени плейсхолдеры на свои значения:

```
BOT_TOKEN=8565672652:AAGpwT7Lg50bSL-SDBgwG15ci0BcSydNAU4
ADMIN_IDS=8128303065
AUTHOR_NAME=Никита
AUTHOR_USERNAME=stendapik
SUPPORT_USERNAME=stendapik
```

`BOT_TOKEN` — то что прислал @BotFather.
`ADMIN_IDS` — твой числовой user_id (узнай через `@userinfobot` — напиши ему `/start`).
`AUTHOR_USERNAME` / `SUPPORT_USERNAME` — твой username в TG **без @**.

Сохранить и выйти: `Ctrl+O` → Enter → `Ctrl+X`.

---

## Шаг 5. Закинь Telethon-сессию

Это файл `apex_discoverer_v.session` — авторизация TG-аккаунта на котором парсер читает чаты.

**На своём ноутбуке** (не на сервере), в любой папке:

```bash
pip install telethon
python3 -c "
from telethon import TelegramClient
c = TelegramClient('apex_discoverer_v.session', 37992056, '60613234526a75894811075d80c5b7f3')
c.start()
print('OK')
"
```

Скрипт спросит номер телефона (того отдельного TG-аккаунта на виртуальном номере!) и SMS-код. После — рядом появится файл `apex_discoverer_v.session`.

Закинь его на сервер через Termius SFTP в `~/leadbot/`.

Проверить что лежит:
```bash
ls ~/leadbot/apex_discoverer_v.session
```

---

## Шаг 6. Запуск одной командой

```bash
cd ~/leadbot
./start.sh
```

Всё. Бот, парсер и разведчик работают в фоне.

---

## Как смотреть что происходит

```bash
tmux attach -t leadbot
```

Появится терминал с тремя вкладками:
- **discoverer** — разведчик чатов
- **indexer** — парсер сообщений
- **bot** — клиентский бот

Переключение: **Ctrl+B затем 1 / 2 / 3** (по номеру вкладки)
Выйти не убивая: **Ctrl+B затем D** (всё продолжит работать в фоне)

Логи также пишутся в `logs_*.log` — можно смотреть `tail -f logs_bot.log`.

---

## Как остановить

```bash
tmux kill-session -t leadbot
```

---

## Как тестировать что всё работает

1. Открой своего бота в Telegram → `/start` → должен прийти лид-магнит
2. Жми **«🎯 Разбор моей ниши»** → введи `ремонт квартир в Москве`
3. Жди 30–60 секунд → бот покажет pre-check и 1 бесплатный лид

⚠️ **Важно:** если ты только что запустил парсер и БД пустая, лидов не будет. Парсеру нужно 1–2 часа чтобы накопить корпус, потом тест получится.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| `./setup.sh: command not found` | Сначала `chmod +x setup.sh` |
| `nano: command not found` | `sudo apt install nano` |
| Бот не отвечает на `/start` | `tmux attach -t leadbot` → вкладка bot → смотри ошибку. Часто — кривой BOT_TOKEN в `.env` |
| Парсер падает с FloodWait | Это норма, антифлуд встроен. Но подожди час и перезапусти `./start.sh` |
| `apex_discoverer_v.session` нет | Шаг 5 |

Не получается — пиши мне (Devin) с конкретной ошибкой из логов. Не угадывай.
